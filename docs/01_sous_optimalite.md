# La sous-optimalité constitutive

> FR / EN · CC0 · `sig:0x4D5454562D464C50`

**FR** — *« Le vivant n'est pas sous-optimal POUR être robuste : il est robuste PARCE QU'il est sous-optimal. »* L'hyper-optimisation top-down produit un **optimum dégénéré** (résonance 0.0) : parfait en régime nominal, effondré dès que l'environnement fluctue.

**EN** — *"Life is not sub-optimal IN ORDER TO be robust: it is robust BECAUSE it is sub-optimal."* Top-down hyper-optimization produces a **degenerate optimum** (resonance 0.0): perfect in nominal regime, collapsed as soon as the environment fluctuates.

The trap: a perfectly tuned system is a fragile system. Local imperfection buys global resilience — that is the constitutive sub-optimality.

C'est un **capteur de fragilité**.
