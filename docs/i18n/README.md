# `i18n/` — traductions et glossaires

↑ [Retour à `docs/`](../README.md) · [Retour au README du dépôt](../../README.md)

Une traduction de ce dépôt n'est pas un exercice de style : elle doit rester **vérifiable**.
Les chiffres ne changent pas, les déclarations de choix survivent, et les sorties de programme
restent dans leur langue d'origine — traduire un `VERDICT : dépôt cohérent` rendrait le document
non reproductible.

## Règles, en trois lignes

1. **Un glossaire avant la traduction**, pas après : [`en.md`](en.md) fixe les termes non traduits
   (`B-gate`, `handshake`, `fail-open`, `graine`) et les correspondances retenues.
2. **Aucun arrondi.** `0,5877` devient `0.5877`, jamais `0.59`.
3. **Toute traduction cite la version** dont elle est issue : `1.2.1`, `10.5281/zenodo.23869556`.

La procédure complète de contribution (revue, critères d'acceptation d'une traduction) est dans
[`CONTRIBUTING.md`](../../CONTRIBUTING.md), section « Traduire sans trahir ».
